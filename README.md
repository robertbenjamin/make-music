# The CAM System: a follow-along guide

**Live:** https://cam.robertbenjamin.co

An unofficial, fan-made study guide to **Luca Bade**'s video
[*Finish music whenever you want (with this system)*](https://www.youtube.com/watch?v=pOvyNUoNOng).

## What's on the page

- His whiteboard as a clickable map of the three stages, each with two phases and a
  checkpoint, plus progress tracking.
- For every phase: the mindset in one line, why it exists, goal, mindset, what to avoid, and
  a "move on when" checklist.
- **Focus mode** (`F`): one phase per screen, with stage/phase navigation and keyboard
  shortcuts (`←` `→`, `1`–`9`, `D`, `T`, `?`).
- Tools for working along: a session timer for experimenting, first-listen notes you can
  prioritise and tick off, and redrawn versions of his diagrams.
- A Streamlined / In depth switch for the mix stage.
- Light and dark themes.

Progress, notes and settings are stored in your browser's `localStorage` only. Nothing is sent
anywhere.

## Running it

It's a single static `index.html` with no build step. Open it in a browser, or serve the
folder with any static server, for example `python3 -m http.server`.
